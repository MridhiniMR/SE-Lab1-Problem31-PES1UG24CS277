# Multi-Vendor Artisan E-Commerce Marketplace

## Software Engineering Individual Project

**Problem Statement:** #31  
**Domain:** Retail, E-Commerce & Finance  
**Institution:** PES University – Department of Computer Science and Engineering

---

## Project Overview

The Multi-Vendor Artisan E-Commerce Marketplace is an online marketplace that enables independent craftspeople to set up storefronts, manage product catalogs, receive orders, and receive automated split payouts with platform commission deductions.

### Target Actors

- Shopper
- Artisan Vendor
